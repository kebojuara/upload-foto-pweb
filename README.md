# Student Data CRUD with Photo Upload

---

## About
This repository contains a student data management assignment for the **Web Programming** course at **Institut Teknologi Sepuluh Nopember, Surabaya**.  

It is a PHP and MySQL application for adding, viewing, editing, and deleting student records, including student photos.

---

## How to Run
1. Clone this repository:
   ```bash
   git clone https://github.com/kebojuara/upload-foto-pweb.git
   cd upload-foto-pweb
   ```
2. Create a MySQL database and import `database siswa.sql`.
3. Update the database connection in `koneksi.php` with your local MySQL credentials.
4. Create an `images` folder in the project directory and ensure PHP can write uploaded photos to it.
5. Start a local PHP server:
   ```bash
   php -S localhost:8000
   ```
6. Open `http://localhost:8000` in your browser.
